## 本版本内容

### 修复"不合格后未点再次挑战、反而退出小程序"（44/45.jpg）

**根因**（45.jpg 日志实锤）：AI 答错不合格后，结果页加载期间 WebView 树塌缩成 **1 个节点**——"再次挑战"按钮不在树里找不到，代码走了 back() 兜底，而**结果页是小程序的最后一页，返回键直接退出了小程序**（45.jpg 微信主页+"等待页面"卡死）。

**修复**：
1. **失败分支专等按钮**：轮询 15 秒专等"再次挑战/重新通关"出现（树塌缩时自动 poke 自愈），找到即点击（直达小测阶段重答，不重做朗读）；**找不到则暂停 + 明确提示，绝不 back()**；
2. **全局 back() 拦截**：当前屏幕是微信主页（消息/通讯录/发现/我四标签齐全）时，back() 拒绝执行——从机制上封死"返回键退出小程序"的路径，所有调用点统一受保护；
3. **意外退出可行动提示**：任务中检测到已退回微信主页 → 暂停 + 提示"⚠ 小程序已退出，请重新打开到话术通关列表后点『▶ 继续』"（引擎无法自行重新进入小程序，暂停是诚实的做法）；
4. **失败页加载判定放宽**：失败页没有"通关排名"标题（44.jpg 实证），不再强等它——排名表 + 双计数齐备即视为加载完成，减少 20 秒空烧。

### 关于返回键的说明（回应疑问）

您的理解正确：实测多款小程序，系统返回键在小程序的最后一页会**直接退出小程序**。已修正设计原则——**结果页永远不使用 back()**（只点按钮），全局 back() 增加微信主页拦截；back() 仅用于小程序内部的"返回上一页"场景。
