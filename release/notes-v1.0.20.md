# 学习通关助手 v1.0.20

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.20.apk`：安装包（versionCode 20，已签名；覆盖安装自动保留数据）

## 本版本内容

修复 v1.0.19 实测发现的"已通过后停在当前页"（22.jpg：评测 88% 已通过 → WebView 树再次塌缩成 18 节点 → 引擎线程异常退出 gen=1，悬浮窗显示"已停止"）：

- **残树推进改记忆位置盲点**：推进"下一题"时若树塌缩（节点数<25），直接按此前记忆的位置点击，不再等树恢复——位置记忆机制真正用在刀刃上
- **引擎异常死亡自动重启**：线程抛异常退出时自动以新代数重启（上限 5 次防崩溃风暴），悬浮窗提示"⚠ 引擎异常，自动重启(N/5)"；用户手动停止不受影响
- 两层修复叠加后：树塌缩 → 盲点推进（通常直接成功）→ 即使引擎死亡也会自动复活继续任务
