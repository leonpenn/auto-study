## 本版本内容

### AI 接口可用性增强

**① 测试连接错误翻译为中文原因**

设置页"保存并测试连接"失败时，不再显示原始 HTTP 状态码+响应片段，而是直接给出可操作的结论：

| 场景 | 提示 |
|---|---|
| Key 无效/过期（401） | "Key 无效或已过期，请检查 API Key" |
| 欠费/额度不足（402 或响应含欠费关键词） | "账号欠费/额度不足，请前往服务商充值" |
| 无权限（403） | "无权限（Key 未开通该模型或账号受限）" |
| 模型名错误（404） | "模型名不存在，请检查模型名拼写" |
| 频率限制/额度耗尽（429） | "请求过于频繁或额度耗尽（欠费常见），稍后重试或检查余额" |
| 服务商故障（5xx） | "服务商故障，请稍后再试" |
| 网络问题 | "无法解析服务器地址" / "连接超时/失败" |

**② 运行中 AI 健康监控**

此前测试连接只能验证"当下能用"，跑题中途额度耗尽会静默转入蒙题。现在：

- AI **连续失败 5 次**（欠费/Key 失效的典型特征，偶发网络抖动不会触发）→ 悬浮窗提示"⚠ AI接口异常已转蒙题：具体原因"+ 震动一次 + 日志记录；
- **恢复成功**自动提示"AI接口已恢复"；
- 引擎重启时监控复位。
