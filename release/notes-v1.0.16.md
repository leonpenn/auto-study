# 学习通关助手 v1.0.16

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.16.apk`：安装包（versionCode 16，已签名；华为/荣耀鸿蒙 4.x 及以下可装，HarmonyOS NEXT 不支持）
- 覆盖安装旧版本请使用同一签名（本仓库 keystore），数据/题库/战绩自动保留

## 本版本内容

- 蒙题逻辑修复：多选"全选"被证伪后，重试改为从未证伪选项随机子集（原会重复提交同样错误答案）
- 主界面按钮整体左移，避免被右侧悬浮窗遮挡
- 新增《产品设计开发文档》：架构、核心流程、设计决策与教训、v1.0.0 → v1.0.16 完整版本变迁

## 核心能力（自 v1.0.0 累积）

- **全流程自动化**：通关列表 → 朗读学习（TTS 真声跟读+语音评测）→ 小测作答 → 通关反馈 → 结果记分 → 自动下一个专题
- **三级答案策略**：本地题库缓存 → 大模型（OpenAI 兼容，智谱免费模型即可）→ 蒙题兜底（单选顺延、多选全选、错题规避）
- **朗读评测闭环**：以最新"已通过/未通过"标识为准，未通过自动重录，通过自动推进
- **位置记忆盲点**：话筒与"下一题"按钮识别一次持久化，无障碍树塌缩时照常操作
- **多级自愈**：空树/残树检测 → 配置自愈 → 返回重进（进度续上）→ 跳过，绝不死循环
- **真实触屏点按**：全 App 统一模拟手指点按（小程序不响应无障碍合成点击）
- **可观测性**：30 秒心跳、页面 dump、分级日志，悬浮窗即看即分享
