# 学习通关助手 v1.0.29

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.29.apk`：安装包（versionCode 29，已签名；覆盖安装自动保留数据）

## 本版本内容

### TTS 检测改为"实测朗读"判定（适配 ColorOS16 等新引擎）

OPPO A5 Pro（ColorOS 16 / Android 16）实测发现：系统自带 TTS Accessibility Engine 的 `setLanguage(中文)` 返回 -2（声明不支持），但引擎实际配有中文音色、系统试听可正常朗读中文——即**声明与实际能力脱节**。

- **检测重写**：不再以 setLanguage 声明为结论。检测时真实调用朗读"测试"一词，引擎在 6 秒内**开口即判定可用**（提示"引擎未声明中文(set=-2)，实测可朗读"）；仅实测也不朗读才判定不可用
- **运行时验证**：引擎启动预热增加"开口验证"，预读未真正发声才提示"建议安装第三方语音引擎"
- ColorOS16 / Android16 设备（OPPO/一加/真我同系）检测将不再误报

### 其他

- 临时截图归档至 local/ 目录；FAQ 补充 OPPO/ColorOS 的 TTS 说明
- 若实测朗读也不可用：安装"讯飞语记"等第三方 TTS 引擎，并在 系统→文字转语音→首选引擎 中选用
