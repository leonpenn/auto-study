# 学习通关助手 v1.0.19

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.19.apk`：安装包（versionCode 19，已签名；覆盖安装自动保留数据）

## 本版本内容

- **修复"话筒按住不放"**：长按录音模式的按压时长估算偏差 2~3 倍（200 字会按满 59 秒上限，朗读早结束手指仍按着）——现按实际语速估算并阻塞等待按压真正结束，期间不派发任何其他手势，杜绝录音被中途取消截断
- 首次点按未录上改为重点一次（去掉会截断录音的 1.2 秒长按试探）
- **每个新专题自动重置回点按录音模式**（点按历史表现最好，长按仅作专题内兜底），一次偶发失败不再污染整轮运行
- 录音模式切换在悬浮窗可见提示，日志记录按压时长与字数

## 核心能力（自 v1.0.0 累积）

- **全流程自动化**：通关列表 → 朗读学习（TTS 真声跟读+语音评测）→ 小测作答 → 通关反馈（五星好评）→ 结果记分 → 自动下一个专题
- **三级答案策略**：本地题库缓存 → 大模型（OpenAI 兼容，智谱免费模型即可）→ 蒙题兜底（单选顺延、多选全选、错题规避）
- **朗读评测闭环**：以最新"已通过/未通过"标识为准，未通过自动重录，通过自动推进
- **位置记忆盲点**：话筒与"下一题/提交"按钮识别一次持久化，无障碍树塌缩时照常操作
- **真实触屏点按**：全 App 统一模拟手指点按（小程序按钮不响应无障碍合成点击）
- **多级自愈**：空树/残树检测 → 配置自愈 → 返回重进（进度续上，已通过题直接推进）→ 跳过，绝不死循环
- **可观测性**：30 秒心跳、页面 dump、分级日志，悬浮窗即看即分享
