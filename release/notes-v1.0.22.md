# 学习通关助手 v1.0.22

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.22.apk`：安装包（versionCode 22，已签名；覆盖安装自动保留数据）

## 本版本内容

评分页新增**第三重兜底——横向扫描**。此前两轮（星星节点定位、几何比例定位）若都失败，说明 5 星行的位置估计与实际页面有偏差，此时不再猜测：

- 在星级行高度上，从屏宽 10% 到 52% **从左到右扫描 9 个候选点**（每点间隔 400ms）；
- 利用星级组件"**以最后一次点击为准**"的特性：扫描覆盖真实星星行时，最右侧的点必然落在第 5 颗星上 → 最终评级就是 5 星好评；
- 扫描中弹层意外消失会立即结束；扫描完成后自动提交；弹层仍在（评分必填但扫描全偏）才尝试关闭放行。

配合前两轮，评分页现在共三层策略：星星节点定位 → 几何比例定位 → 横向扫描，评分环节基本不可被卡住。
