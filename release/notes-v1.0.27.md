# 学习通关助手 v1.0.27

免 Root 安卓自动化工具：自动完成微信小程序「话术通关」的朗读学习 + 小测任务，直至未通关清零。

## 下载

- `auto-study-v1.0.27.apk`：安装包（versionCode 27，已签名；覆盖安装自动保留数据）

## 本版本内容

### 结果页加载等待加强（修复偶发"服务器报错/退出小程序"）

进入通关结果页后，需要**集齐全部 4 个加载标志**才点击"返回通关列表"：
- "通关排名"标题
- "支行网点"列表头
- "已通关(N)"计数
- "未通关(N)"计数

任一缺失则继续等待，**超时 20 秒强制点击**（不再用旧版"任一标志出现即点、最多10秒"的宽松策略）。等待期间如果出现**服务器报错弹窗**（含"重试"按钮），自动点击重试并继续等待。加载是否完整（完整/超时强制）会写入日志。

### 多选题修复的来源定位辅助（v1.0.26 延伸）

多选题遇到 AI 单字母答案时，日志会记录 `AI多选答案仅X一个字母，视为无效转兜底`，结合 `来源=llm/cache/guess` 可直接定位单字母答案的来源。
