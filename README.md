# 学习通关助手 (auto-study)

免 Root 的安卓无障碍自动化工具：自动完成微信小程序「话术通关」的**朗读学习 + 小测**任务。

- 悬浮窗一键启动，自动循环：进入专题 → TTS 真声朗读跟读 → 语音评测 → AI/蒙题作答小测 → 提交反馈 → 记录成绩 → 下一个专题，直至"未通关"清零
- 免 Root、数据仅存本机；答题可选接入 OpenAI 兼容大模型
- 真实触屏点按 + 随机休息节奏 + TTS 真声朗读，尽量拟人
- 多级自愈：无障碍树塌缩/页面异常自动恢复，绝不死循环

## 快速开始

1. 下载 [Release](../../releases) 中的 APK 安装（华为/荣耀：鸿蒙 4.x 及以下，需允许未知来源）
2. 打开 App 完成前置检查：无障碍服务 → 电池白名单 → TTS 检测 → AI Key 配置（可选）
3. 微信进入「话术通关」列表页，点悬浮窗 ▶ 开始

## 构建

```
JDK17 + Android SDK (platform 34) + Gradle 8.7
./gradlew assembleRelease   （签名证书在 keystore/，密码见 app/build.gradle）
```

> ⚠️ 签名证书（keystore/auto-study.jks）与本仓库一同备份，请勿用于正式对外发布的产品；若仓库转为公开请先移除。
